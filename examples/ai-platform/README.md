# Enterprise AI Platform example

A five-slide HTML example showing the bundled warm terminal-editorial visual language.

## Preview

```bash
python3 -m http.server 8000 --directory examples/ai-platform
```

Open `http://localhost:8000`.

## Validate

```bash
node bin/claude-slides.mjs check examples/ai-platform
```

Use `N` for notes, `F` for fullscreen, and `P` to print or export PDF.
