# Warm terminal-editorial presentation system

Read [the visual system](references/style-system.md), resolved relative to this skill directory.

Core intent:

- Warm, calm, technical, and direct.
- Editorial storytelling combined with terminal precision.
- Large claims, restrained color, precise alignment, and functional code or command-line motifs.
- No imitation of Anthropic trademarks, logos, proprietary UI screenshots, or official brand assets.

Always favor communication quality over decorative resemblance. The result should feel inspired by an excellent developer tool, not like a copied product screen.
